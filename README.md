# 🏏 IPL Analysis Dashboard (2008–2025) | Power BI

## 📌 Project Overview
The **IPL Analysis Dashboard** is an interactive Power BI project designed to analyze Indian Premier League (IPL) performance across seasons from 2008 to 2025. It provides insights into team performance, match statistics, player achievements, and tournament results through interactive visualizations and key performance indicators (KPIs).

## 🎯 Project Objectives
- Analyze IPL match statistics across different seasons.
- Compare team performance, wins, losses, and total points.
- Identify top-performing players using Orange Cap and Purple Cap statistics.
- Track batting performance through total runs, boundaries, and centuries.
- Present insights through an interactive dashboard with season-wise filtering.

## 🛠️ Tools & Technologies
- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Measures and calculated metrics
- **Data Modeling** – Organizing data for meaningful analysis

## 📊 Dashboard Features
- **Season Selection:** Filter dashboard data by IPL season.
- **Tournament Summary:** View total matches, teams, venues, sixes, fours, centuries, and half-centuries.
- **Champion & Runner-up:** Display the season's champion and runner-up teams.
- **Orange Cap Statistics:** Analyze the highest run-scorer and total runs.
- **Purple Cap Statistics:** Identify the leading wicket-taker and wicket count.
- **Batting Performance:** Track total fours and sixes scored by players in a season.
- **Points Table:** Compare teams based on matches played, wins, losses, no results, ties, and total points.

## 💡 Key Insights
- Compare team performance across IPL seasons.
- Identify leading batsmen and bowlers.
- Understand batting trends through boundaries and century statistics.
- Evaluate team standings using wins, losses, and points.
- Explore season-wise tournament statistics using interactive filters.
